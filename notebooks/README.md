# Benchmark notebooks

These are inherited exploratory notebooks for TimeEval analysis, plotting,
parameter optimization, and dataset preparation (`data-prep/`). Filenames and
locations are retained because notebook cells can depend on relative paths.
They are reference material; the active thesis training entry point is
`python -m esa_thesis train` from the repository root.

Notebook outputs and machine-specific paths have not been re-executed or validated.
Mission timeline notebooks remain beside their original utilities in `../scripts/`.
